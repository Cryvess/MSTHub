# MSTHub

MSTHub is a Roblox Lua script hub featuring a variety of movement, visual, Murder Mystery 2, and miscellaneous features.

## Usage

Paste the following into your executor:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/Cryvess/MSTHub/refs/heads/main/MSTHub.txt"))()
```

## Features

### 🏃 Movement

* Infinite Jump
* Walk Speed
* Jump Power
* Fly
* Noclip
* Teleport to Player
* Refresh Player List

### 👁️ Visual

* ESP
* Fullbright
* FOV Changer

### 🔪 Murder Mystery 2

* Murderer ESP
* Sheriff ESP
* Innocent ESP
* Distance ESP
* Gun Drop ESP
* Auto-Grab Gun
* Sheriff Aimbot
* Kill All
* Touch Fling
* Auto Collect Coins
* Teleport to Gun

### 🎭 Misc

* Emotes
* Spin
* Sparkles
* Fire
* Headless Effect
* Invisible Right Leg
* Anti-AFK
